# OpenNest

免账户、直连存储的文件客户端。桌面端（Windows）与 Android 共用一套 Flutter 代码。

## 它是什么

OpenNest 安装即用：没有注册、没有登录页、没有账号体系。首次启动时会自动拉起内嵌的 OpenList 引擎（本机回环地址上的受管子进程），随后只需回答一个问题——**你想连接哪个存储**。本地目录、网络附加存储、对象存储、网盘、分享链接、其它 OpenList 服务器，都只是一条「存储源」配置。

引擎自带 85 个存储驱动，添加存储源时的表单由驱动自身的字段定义动态生成，客户端不需要为每个驱动单独写界面。

## 关键设计

| 项 | 做法 |
|---|---|
| 免账户 | 引擎管理员口令固定为 `admin`（引擎只监听 `127.0.0.1`，不对局域网暴露）；启动直接以该口令登录，没有登录页、口令输入或校验
| 只监听本机 | 引擎绑定 `127.0.0.1`，端口随机分配并持久化，不对局域网暴露 |
| 便携 | 所有数据（配置、数据库、日志、传输临时文件）都在程序目录的 `userdata/` 下，解压即用、复制即走 |
| 字体 | 桌面端统一 Arial（中文回退到与 Arial 最接近的无衬线黑体：微软雅黑 / 苹方 / 思源黑体）；安卓保持系统字体 |
| 首启 | 无账户、无登录页：首屏即「连接第一个存储」，也可粘贴分享链接导入，或点「稍后再说」先进空态 |
| 单一存储 | 全部本地数据进 `userdata/opennest.db`（SQLite），不再有 JSON 配置文件 |
| 传输 | 下载走签名直链 + 断点续传；上传走流式接口；失败自动重试 |
| 界面 | **只有一套浅色主题**（不提供深色与主题切换），桌面 8 个界面严格对齐设计稿 D1–D8：幽灵按钮、14–20px 卡片圆角、6px 圆角滚动条、零动画 |
| 设置 | 侧栏 5 项：通用 / 存储源 / 传输 / 播放 / 关于；存储源是设置内的一个分区（表格 + 导入导出），不再是独立页面 |

## 数据目录

```
userdata/
├── opennest.db     全部本地数据（设置/浏览位置/下载目录/续播/目录缓存/传输记录/源访问时间）
├── config.json     引擎配置
├── data.db         引擎自身数据库（存储源与账号）
├── logs/           引擎日志
└── sidecar.pid     引擎进程号（防重复启动）
```

`opennest.db` 的表：`settings`（标量偏好）、`ui_state`（每个源的浏览位置与排序）、
`download_dirs`、`resume_positions`、`listing_cache`（离线目录快照）、
`transfer_tasks`、`source_usage`（各存储源的最后访问时间）。

## 构建

本机无需 Flutter 工具链，构建全部交给 GitHub Actions：

- `analyze`：静态检查（仅错误阻断）、版本号一致性、托盘图标校验
- `android-arm64`：产出 `OpenNest-<版本>-android-arm64.apk`
- `windows-x64-portable`：产出 `OpenNest-<版本>-windows-x64-portable.zip`

推送 `v*` 标签时自动创建 Release 并上传产物与 sha256 校验文件。

## 安装

- **Windows**：解压 zip，运行 `OpenNest.exe`。`openlist.exe` 必须与它同目录。
- **Android**：安装 apk。首次启动会在私有目录初始化引擎，受系统限制仅支持 arm64 设备。

## 已知限制

- **Android 16KB 页设备**：内置引擎二进制为 4KB 页对齐（上游产物如此），Android 15 及以上启用 16KB 页的设备无法执行引擎。普通 4KB 页设备不受影响。
- 需要扫码或浏览器授权的驱动（部分网盘）无法在客户端内完成授权，表单会提示。
- 后台传输在系统回收应用后可能中断，重新打开会自动恢复队列。
- 一期只构建 Windows x64 与 Android arm64。
